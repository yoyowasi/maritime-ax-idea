## 확인한 요강

- 마감: 2026년 10월 30일 14:00 한국시간.
- 관심 있는 대학(원)생 개인 참가 가능. 공개 요강에 재직 병행·전공·거주 제한은 없다.
- 서류평가100%. 프로토타입은 선택이고 미제출 감점이 없다. 가점 최대10점, 합산총점 상한100점.
- 기획서는 개요 포함 총10쪽 이내로 작성한다. 서명한 신청서·동의서·기획서를 PDF1개로 제출하고 추가자료는 압축파일1개로 묶는다.
- 제출 파일명은 성명_해운항만물류_AX공모전 형식을 따른다.
- 프로토타입을 제출하면 로그인·설치 없이 확인 가능해야 하며 마감 후 내용 수정이 불가하다.
- 타 공모전 수상작, 공고일 이전 상용화 또는 상용화 예정 제품·서비스 등의 제한을 적용한다.
- 수상 후 12월 발표 일정, PoC·실증·추가개발 등 활용 조항과 상금 외 추가대가 요구 불가 조항을 제출 전 확인한다.

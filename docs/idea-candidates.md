# 해양 AX 주제 후보

아래는 검증할 가설이며 확정된 출품 주제가 아니다. 실제 경험·효과 수치·차별성을 조사 없이 사실로 쓰지 않는다.

### 해양 AX 후보 A 운송 문서 불일치 검토

문제 가설은 운송·정산 과정의 여러 문서에서 수량·날짜·금액·참조번호를 대조하고 수정 요청을 작성하는 업무에 재작업이 생긴다는 것이다. AI가 후보 불일치와 원문 근거를 정리하고 담당자가 최종 확인하는 절차를 제안한다.

문서 종류와 업무 단계 하나를 정해 범위를 좁힌다. 기획서에는 대상 업무, 규칙 검사와 AI 역할, 원문 근거 확인, 예외 처리, 도입 비용과 검증 방법을 담는다. 공개·합성 샘플 확보 가능성과 기존 OCR·문서검증 제품 대비 차별성을 먼저 확인한다.

### 해양 AX 후보 B 인수인계의 미처리 항목 추적

문제 가설은 이메일·문서·메신저에 분산된 처리 요청에서 담당자와 기한이 빠져 인수인계가 누락되는 상황이다. AI가 항목을 추출하고 사람이 확인해 담당·기한·상태를 기록하는 흐름을 검토한다.

일반 업무관리 서비스와의 차이가 약해지기 쉬우므로, 항만·물류의 특정 인수인계 단계와 누락 사례를 확보할 수 있을 때만 채택한다. 실제 현장 근거를 구하기 쉬운 후보를 우선한다.

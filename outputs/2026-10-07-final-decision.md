# 해운·항만·물류 AX 공모전 최종 기획 방향

결정일: 2026-10-07 (한국시간)

## 결론

**MF1 「Draft B/L 승인 전 4자 대조 AI」를 기획 주제로 채택한다.** 부제는 「수출신고필증·SI·Draft MBL·HBL의 근거 대조와 선사별 정정비용 시점 점검」이다. 기획서 중심으로 진행하며 프로토타입은 선택이다.

사용자의 “두 결과를 종합해 각 폴더에 결론을 내리고 GitHub 저장소를 만들자”는 요청에 따라 Claude 최종 결과와 기존 Codex 검토를 통합했다. 기획 방향 결정과 현장 효과 검증·실제 출품·구현·배포는 구분한다.

## 두 검토 결과의 통합

| 항목 | Claude 최종 검토 | 기존 Codex 검토 | 이번 결정 |
|---|---|---|---|
| 우선 주제 | MF1 조건부 단일 권고 | A 계열을 좁혀 검증하되 출품은 보류 | MF1을 기획 기준으로 채택 |
| 범위 | EP·SI·Draft MBL·HBL 및 비용 시점 | 제한 필드·정상 차이·원문 근거 우선 | 문서 역할 차이를 전제로 좁은 FCL 장면부터 설명 |
| AI 역할 | 비정형 필드 추출·잔여 의미 해석·정정 요청 구조화 보조 | 규칙 대비 AI 순효과가 없으면 축소 | 결정적 검사는 규칙, 해석은 AI 보조, 최종 판정은 사람 |
| 효과 | 합성 사례·후속 검증 필요 | 합성 시험은 현장 효과를 입증하지 못함 | 절감률·국내 오류 빈도·도입 의향은 미검증 |

두 회의가 A 계열을 우선한 점을 반영했다. 다만 Claude 사회자는 Codex 종합을 읽고 일부 요소를 반영했으므로 완전한 맹검 결과 두 개로 계산하지 않는다. 모의 심사점수와 후보 간 소수점 차이는 실제 심사·수상 예측 근거가 아니다. 전문가·심사위원 역할은 AI 모의 역할이며 실제 기관·실무자의 의견이 아니다.

## 포함할 최소 범위

- 사용자: 한국 출발 수출 FCL을 맡은 포워더 수출 문서 담당자.
- 시점: 첫 Draft MBL을 받은 뒤 승인 회신하기 직전.
- 입력: 수출신고필증(EP), SI와 개정 이력, Draft MBL, 해당 HBL/House 정보.
- 처리: 문서 역할·필드 의미를 확인한 뒤 제한 필드를 대조하고, EP 분할·병합 합계와 SI 버전 귀속을 검토한다. 정상 차이와 판단 불가를 구분한다.
- 출력: 검토 후보, 원문 위치, 적용 규칙·버전, 불확실성, 담당자의 판정과 조치 초안.
- 시간 안내: 선사별 정정비용 적용 시점과 법정 제출 시점을 분리한다. 출처·적용일이 없는 시간이나 비용은 계산하지 않는다.

모든 선사에 공통된 무료 정정 구간이 있다고 오해할 수 있어 Claude 제목의 “무료 정정 창”은 최종 제목에서 뺀다.

## 제외 범위

- 혼재 화물의 복잡한 MBL 1건:HBL 여러 건 실제 운영 처리, VGM·순중량과 총중량의 단순 동일값 대조.
- 자동 승인·발행·외부 발송, 법적 적합성 보증, 실제 선사 시스템 연동.
- 확인되지 않은 정정비 절감률·처리시간·오류 빈도, 인터뷰·고객 확보·지원 확정 주장.
- MF2·MF3 동시 개발. MF2는 재검토용 예비안, MF3는 이번 준비에서 보류한다.

## 사실과 미검증 가설

이번 통합 검토는 저장된 회의 원문·비판·수정본을 대조했다. 이전 담당자의 공식자료 확인 기록과 이번에 직접 확인한 사실을 구분한다.

| 구분 | 판단과 취급 |
|---|---|
| 직접 확인한 작업 결과 | Claude 최종 회의록·MF1 v2·최종 모의 순위, Codex 종합·양측 비교 문서가 존재한다. |
| 기존 조사 기록 | Hapag-Lloyd 자료, DCSA 표준, 관세 고시 등의 확인 기록이 있다. 이번 결정 작성에서 해당 공식 원문을 새로 검증하지 않았다. 제출용 주장은 최신 원문으로 재확인한다. |
| 오래되거나 예정인 정보 | Maersk EP 가이드는 2023년판의 현재 유효성 확인이 필요하다. 회의의 55,000원은 10월 12일 시행 예정·2차 자료 수준이므로 10월 7일 적용 요율로 쓰지 않는다. |
| 미검증 수요 | 실제 문서 수신 시점·버전·할당 출처, 정상 차이의 빈도, 담당자 불편과 도입 의향. |
| 미검증 효과 | 규칙 대비 AI 추가 가치, 실제 절감 시간·비용, 한국 업무에 맞는 선사별 시간 계산식. |
| 기획 가설 | 제한된 네 문서와 이력으로 승인 전 검토 누락을 줄일 수 있다는 주장. 실증 결과가 아니다. |

## 다음 작업과 판단 기준

1. 공식 양식에 맞춰 한 장 개요와 개요 포함 10쪽 이내 목차를 작성한다.
2. 핵심 규칙 8개와 정상 차이·불확실성 반례 6개를 정하고 미확인 규칙에는 가설 표시를 한다.
3. 기존 제품·DCSA 직접 정정 경로 비교표는 공개 자료에 명시된 기능으로 작성한다. 자료에서 찾지 못한 기능을 “없음”으로 단정하지 않는다.
4. 같은 합성 입력에 단순 비교 → 정규화·규칙 → AI 보조를 적용하는 비교 시험을 설계한다. 오탐·누락·검토량 개선이 없으면 AI 범위를 줄이거나 제거하고 AX 주제 적합성을 재판단한다.
5. 최신 공식 요율·고시·공고와 자료 확보 가능성을 확인한다. 외부 문의·접수·배포는 별도 승인 후 진행한다.

정적 목업을 선택한다면 대조 화면·원문 근거·담당자 판정·설정표까지만 우선한다. 합성 시연 성공은 현장 검증 또는 상용화 준비 완료를 뜻하지 않는다.
